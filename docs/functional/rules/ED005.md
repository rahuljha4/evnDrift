# ED005 — dynamic-access

**Requirement:** FR-RULE-ED005

| Item | Value |
|---|---|
| Milestone | M1.5 |
| Source | [PRD §11](../../prd.md#11-rules), [ADR 0004](../../architecture/adr/0004-report-aliases-not-follow.md) |
| Explain text | [`rules.md`](../../rules.md) |

## Summary
The code reads the environment in a way whose variable name cannot be known statically. EnvDrift cannot check it. It also cannot prove that other variables are unused (D3).

## Fires when
The extractor reports a dynamic access.

| Property | Value |
|---|---|
| Default severity | `info` |
| Locations reported | The access (file, line, column) |
| `name` | Not set |

## Kinds

| Kind | Example | Catalogue |
|---|---|---|
| `computed-key` | `process.env[key]`, `` process.env[`DB_${region}`] ``, `getEnv(name)` | D01, D02, A-rows |
| `rest-destructuring` | `const { A, ...rest } = process.env` | D03 |
| `alias` | `const env = process.env`, `const { env } = process`, `fn(process.env)`, `{ ...process.env }` | D04, D05 |

See [`patterns-catalogue.md`](../../patterns-catalogue.md).

## Message template
`Dynamic env access (<kind>): variable names here cannot be checked`

## Fix template
`Use a literal name (process.env.NAME), or suppress with // envdrift-ignore ED005 if intentional`

## Examples

**Fires**
```ts
export const get = (k: string) => process.env[k];
```
→ `ED005 info src/env.ts:1 (computed-key)`

**Does not fire**
- `process.env['API_URL']` has a literal key, so it is a reference (P02).
- `process.env.X = '1'` is a write, which is negative pattern N02.

## Interactions

| Aspect | Behaviour |
|---|---|
| D3 | Any dynamic access triggers the ED003 downgrade unless `--strict` is given. Whether suppressed accesses count is an open question; see [ED003](ED003.md). |
| Suppression | `// envdrift-ignore ED005` on the line or the line above. `// envdrift-ignore-file ED005` in the first 10 lines suppresses every access in the file. |
| Aliases | Never followed ([ADR 0004](../../architecture/adr/0004-report-aliases-not-follow.md)). Reads through an alias produce no references. |

## Required tests (`packages/core/test/rules/ED005.test.ts`)
1. **Positive:** `ED005 fires once per dynamic access with its kind`.
2. **Negative:** `ED005 does not fire for literal-key or template-without-expression access`.
3. **Suppression:** `ED005 is dropped by same-line, line-above, and file-level envdrift-ignore`.
