# ED004 — env-mismatch

**Requirement:** FR-RULE-ED004

| Item | Value |
|---|---|
| Milestone | M3.3 |
| Source | [PRD §11](../../prd.md#11-rules) |
| Explain text | [`rules.md`](../../rules.md) |

## Summary
Environments have drifted apart. A name is declared in some environments but not in others, whether or not the code uses it.

## Fires when
At least 2 environments are configured, and a name is declared in some but not all of them. This is independent of code usage.

| Property | Value |
|---|---|
| Default severity | `warning` |
| Locations reported | The declarations, in the environments that have the name |
| `environments` | The environments where the name is **missing** (sorted) |

## Grouping
There is one finding per name.

## Message template
`<NAME> is declared in <present envs> but missing in <missing envs>`

## Fix template
`Add <NAME> to <missing envs>, or remove it from <present envs> if no longer needed`

## Examples

**Fires**
- `staging` (`deploy/staging.env.keys`) declares `FEATURE_FLAGS_URL`.
- `production` (Dockerfile) does not.
- Result: `ED004 warning FEATURE_FLAGS_URL deploy/staging.env.keys:7 environments=[production]`

**Does not fire**
- Only one environment is configured, or `--env` selects only one.
- The name is declared in every environment.
- The name is ignored.

## Interactions

| Aspect | Behaviour |
|---|---|
| ED002 overlap | If code reads the name without a fallback, ED002 also fires for the missing environment. This is intended: ED002 is about the crash, and ED004 is about the drift. |
| Example file | Not an environment; it never counts for ED004 |
| Suppression | `# envdrift-ignore ED004` above the key in any dotenv or keys source suppresses that location. The finding is dropped when all locations are suppressed. |
| D3 | Not affected |

> **Open question:** should ED004 be skipped when ED002 already fires for the same name and environment, to avoid double findings? *Proposal:* no. Keep both, as the PRD defines them independently. The rule docs explain the overlap.

## Required tests (`packages/core/test/rules/ED004.test.ts`)
1. **Positive:** `ED004 fires when a name is in staging but not production, listing missing envs`.
2. **Negative:** `ED004 does not fire with one environment or when declared everywhere`.
3. **Suppression:** `ED004 is dropped when all declaring locations carry envdrift-ignore ED004`.
