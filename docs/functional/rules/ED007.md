# ED007 — committed-env-file

**Requirement:** FR-RULE-ED007

| Item | Value |
|---|---|
| Milestone | M3.3 |
| Source | [PRD §11](../../prd.md#11-rules) |
| Explain text | [`rules.md`](../../rules.md) |

## Summary
A real `.env` file containing values is tracked by Git. Anyone with read access to the repository can see the values.

## Fires when
A Git-tracked file matching `.env` or `.env.*` has at least one declaration with `hasValue`.

The files `.env.example`, `.env.sample` and `.env.template` are excluded.

| Property | Value |
|---|---|
| Default severity | `error` |
| Locations reported | The file, line 1 |
| `name` | Not set |

## Inputs
- `trackedEnvFiles` comes from `cli/io/git.ts` ([sources.md FR-SRC-12](../sources.md#fr-src-12--git-tracked-env-files-ed007-input)).
- Each file is parsed by the dotenv parser. Only `hasValue` booleans reach the rule ([ADR 0006](../../architecture/adr/0006-values-never-leave-parsers.md)).

## Grouping
There is one finding per file.

## Message template
`<file> is tracked by Git and contains <K> variables with values`

## Fix template
`git rm --cached <file>, add it to .gitignore, and rotate any real secrets it contained`

## Examples

**Fires**
`git ls-files` lists `.env.production`, which contains `DATABASE_URL=<something>`. The result is `ED007 error .env.production:1`.

**Does not fire**
- `.env.example` is tracked. It is excluded by name. ED008 covers values in it.
- `.env.local` exists but is git-ignored or untracked.
- The tracked `.env.ci` file only has empty values (`KEY=`).
- The directory is not a Git repository. A warning is emitted instead.

## Interactions

| Aspect | Behaviour |
|---|---|
| Ignore | `ignore` is name-based. A file finding has no name, so ignore does not apply. Variables in the ignore list are still excluded from the count `K`. |
| Suppression | `# envdrift-ignore ED007` on line 1 of the tracked file |
| D3, `--env` | Not affected |

> **Open question:** should a suppression on line 1 of a tracked `.env` be honoured? *Proposal:* yes, for files that intentionally hold non-secret defaults, such as `.env.defaults` style files. The suppression still counts in `suppressed`.

## Required tests (`packages/core/test/rules/ED007.test.ts`)
1. **Positive:** `ED007 fires for a tracked .env.* file with at least one valued key, at line 1`.
2. **Negative:** `ED007 does not fire for .env.example/.sample/.template or files with only empty values`.
3. **Suppression:** `ED007 is dropped by '# envdrift-ignore ED007' on line 1`.

The fixture `committed-env` covers this end to end, including a real `git init` inside a temporary directory.
