# ED008 — example-has-value

**Requirement:** FR-RULE-ED008

| Item | Value |
|---|---|
| Milestone | M3.3 (cut 5th if behind) |
| Source | [PRD §11](../../prd.md#11-rules), [§10.7](../../prd.md#10-extraction-and-source-parsing) |
| Explain text | [`rules.md`](../../rules.md) |

## Summary
`.env.example` is committed and shared. One of its entries holds a value that looks like a real secret.

## Fires when
A `.env.example` declaration has `looksSecret`.

| Property | Value |
|---|---|
| Default severity | `warning` |
| Locations reported | The declaration |

## Detection
- `looksSecret` is computed inside the dotenv parser by `looksLikeSecret(value)` ([sources.md FR-SRC-10](../sources.md#fr-src-10--secret-detection-secretsts)).
- The rule only sees the boolean. The value is never in the finding.

## Message template
`<NAME> in .env.example has a value that looks like a real secret`

## Fix template
`Replace the value with an empty string or a placeholder, and rotate the secret if it was real`

## Examples

**Fires**
`STRIPE_SECRET_KEY=<a value starting with sk_live_>` gives `ED008 warning STRIPE_SECRET_KEY .env.example:3`. The finding shows no value.

**Does not fire**

| Line | Reason |
|---|---|
| `STRIPE_SECRET_KEY=` | Empty value |
| `STRIPE_SECRET_KEY=your-stripe-key-here` | Placeholder |
| `APP_URL=http://localhost:3000` | localhost URL placeholder |
| `example: null` in config | No example file to check |

## Interactions

| Aspect | Behaviour |
|---|---|
| Ignore | Names in the merged ignore list never fire |
| Suppression | `# envdrift-ignore ED008` above the key |
| Environments | Not checked. Only the example file is in scope. |

## Required tests (`packages/core/test/rules/ED008.test.ts`)
1. **Positive:** `ED008 fires for an example declaration with looksSecret true`.
2. **Negative:** `ED008 does not fire for empty or placeholder values, or environment sources`.
3. **Suppression:** `ED008 is dropped by '# envdrift-ignore ED008' above the key`.

The redaction fixture `planted-secrets` asserts that the planted value never appears in any output.
