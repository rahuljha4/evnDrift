# ED001 — missing-in-example

**Requirement:** FR-RULE-ED001

| Item | Value |
|---|---|
| Milestone | M1.5 |
| Source | [PRD §11](../../prd.md#11-rules) |
| Explain text | [`rules.md`](../../rules.md) |

## Summary
Code reads a variable that `.env.example` does not declare, so new joiners will not know to set it.

## Fires when
`.env.example` is configured and a referenced name has no declaration in it.

| Property | Value |
|---|---|
| Default severity | `error` |
| Locations reported | Every reference of that name, sorted by file then line |
| `environments` | Not set |

## One finding per name
There is one finding per missing name, not one per reference. The locations array carries all the references.

## Message template
`<NAME> is read in code but not declared in .env.example`

## Fix template
`Add <NAME>= to .env.example (or run: envdrift fix --example)`

## Examples

**Fires**
```ts
// src/mail.ts
const key = process.env.SENDGRID_API_KEY;
```
```dotenv
# .env.example
DATABASE_URL=
```
→ `ED001 error SENDGRID_API_KEY  src/mail.ts:2`

**Does not fire**
- `.env.example` contains `SENDGRID_API_KEY=`.
- `example: null` is set in the config.
- `SENDGRID_API_KEY` is in `ignore`.

## Interactions

| Aspect | Behaviour |
|---|---|
| Fallbacks | A reference with a fallback still fires ED001. The example should document every variable, including optional ones. |
| Ignore | Names in the merged ignore list never fire. |
| Suppression | `// envdrift-ignore ED001` on or above a reference removes that location. The finding is dropped only when **all** its locations are suppressed ([suppression.md](../suppression.md)). |
| D3 / D5 | Not affected |
| `--env` | Not affected |
| Test-only references | Excluded by the D2 default `exclude` |

## Required tests (`packages/core/test/rules/ED001.test.ts`)
1. **Positive:** `ED001 fires for a referenced name absent from the example, listing all references`.
2. **Negative:** `ED001 does not fire when the name is declared, ignored, or example is null`.
3. **Suppression:** `ED001 is dropped when every reference carries envdrift-ignore ED001`.
